1. NODE-TO-NODE LATENCY (P2P GossipSub Overlay)
--------------------------------------------------------------------------------
Measures the time elapsed from when an originating node publishes a transaction
envelope via libp2p GossipSub until the receiving peer's network handler unpacks
and validates the payload.

• Transport Stack: TCP + @chainsafe/libp2p-noise encryption + @libp2p/mplex
• Gossip Protocol: libp2p-gossipsub v14.1.2 (mesh topic: "mesh:transactions")
• Measured Over: 50 successive continuous replication cycles

Empirical Results:
  - Minimum Latency:        1.77 ms
  - Median Latency (P50):   2.97 ms
  - Mean Latency:           3.36 ms
  - 95th Percentile (P95):  6.62 ms
  - 99th Percentile (P99):  7.26 ms
  - Maximum Latency:        7.26 ms
  - Jitter:                 ±1.22 ms

Analysis:
  Because the transport utilizes persistent TCP streams secured by Noise Diffie-
  Hellman handshakes, steady-state messaging bypasses per-transaction handshake
  overhead, yielding sub-5 millisecond node-to-node hops on local subnets.
